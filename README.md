# Kevin Phi Dinh – Portfolio

Personal website for Kevin Phi Dinh, cybersecurity graduate (BSc, Kristiania University College, 2025).

The look changes with the seasons based on today's date:

| Months  | Season | Animation                         | Pile at the bottom          |
|---------|--------|-----------------------------------|-----------------------------|
| Sep–Nov | Autumn | Falling leaves                    | Leaf pile                   |
| Dec–Feb | Winter | Snowflakes                        | Snowdrift                   |
| Mar–May | Spring | Dandelion seeds drifting by       | Grass with dandelions       |
| Jun–Aug | Summer | Sun glow and rising heat          | Sand dune with shells       |

Move the mouse over the pile at the bottom to stir it up.

## Run locally

It is a single static page. Open `index.html` in a browser, or serve the folder with any static server.

To preview a season, add `#winter`, `#spring`, `#summer` or `#autumn` to the address.
The season preview buttons can be turned off with `SHOW_SEASON_SWITCHER = false` in `index.html`.

## Deploy

Import this repository in [Vercel](https://vercel.com/new). No build step is needed: Framework Preset "Other", output directory = repository root.
